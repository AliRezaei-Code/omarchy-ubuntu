# Test files that fail on the CI runner for reasons the port does not own, one
# name per line, without the -test.sh suffix.
#
# `./test/all` exits non-zero on any failure, and this tree has carried failures
# like these since before the port started, so a job that requires zero
# failures is permanently red -- and a permanently red build is
# indistinguishable from a broken one, which trains everyone to ignore it.
# `bin/omarchy-ci-suite` compares a run against this list in both directions: a
# new failure fails the build, and so does a name here that no longer fails,
# because a list of things that are wrong is only evidence while it is true.
#
# This is the ubuntu-22.04 runner's baseline, taken from an actual run rather
# than from a developer machine: they differ. The runner has `lua` installed
# and a different umask, so eleven files that fail on a workstation pass there
# and must not be listed.
#
# Each entry says why, so a line here is never a mystery. A name is removed the
# day its cause is fixed, and the build says so if that day has already passed.

# --- this is upstream's own drift, and the port does not own it -----------
# bin/omarchy-theme-set-vscode writes a real file on purpose, because the
# _watch watcher needs a same-inode rewrite, and test/cli still asserts a
# symlink.
cli

# --- the tool or the machine the runner has --------------------------------
# magick, mise and the plocate/xkb tools are not installed on the runner, and
# these assertions need them.
bar-text-color
mise-work-path
powerprofiles-set
windows-key

# The runner's umask is 002, so migration files are written 0644 and the tests
# that require it pass. A workstation with umask 0002 fails these instead --
# which is why they are named here in a comment rather than on the list, and
# why the list has to come from a runner and not from a developer's machine.
#   hermes-skin-migration, omasnap
# system-sleep-ownership-migration fails here too, but for a different reason
# -- it quarantines a path behind a root-only directory the runner's layout does
# not reproduce -- so it is on the list below.
# Same for nopasswd-sudo-expiry, which needs a privileged helper the runner
# does not have.

# The tree is not root-owned, so omarchy-plymouth-set refuses to publish.
plymouth-set

# Hardware the runner does not have.
hw-hybrid-gpu
windows-vm
