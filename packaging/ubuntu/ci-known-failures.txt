#   config, hw-nvidia, hyprland-*,        those tests need lua, and the
#   keybindings-menu, toggle-input-device  checks assert Hyprland behaviour
#   clipboard, notification-send,         content assertions that do not hold
#   agent-usage-fireworks-scanner         on this host

#   plymouth-set                          the tree is not root-owned
#   hw-hybrid-gpu, snapper                hardware and Arch packaging
