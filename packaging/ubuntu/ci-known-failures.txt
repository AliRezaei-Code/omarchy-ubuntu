# Test files that fail on the CI runner for reasons the port does not own, one
# name per line, without the -test.sh suffix.
#
# `./test/all` exits non-zero on any failure, and this tree has carried failures
# like these since before the port started, so a job that requires zero
# failures is permanently red -- and a permanently red build is
# indistinguishable from a broken one, which trains everyone to ignore it.
# `bin/omarchy-ci-suite` compares a run against this list in both directions: a
# new failure fails the build, and so does a name here that no longer fails,
# because a list of things that are wrong is only evidence while it is true.
#
# This is the ubuntu-22.04 runner's baseline, taken from an actual run rather
# than from a developer machine. They are not the same machine, and getting
# that wrong is what the first CI run did: it listed eleven files that pass on
# the runner, and the gate correctly reported the list as stale.
#
# Each entry says why, so a line here is never a mystery. A name is removed the
# day its cause is fixed, and the build says so if that day has already passed.

# --- upstream's own drift, and the port does not own it -------------------
# bin/omarchy-theme-set-vscode writes a real file on purpose, because the
# _watch watcher needs a same-inode rewrite, and test/cli still asserts a
# symlink.
cli

# --- the tool the runner does not have -------------------------------------
#   bar-text-color  magick
#   mise-work-path  mise
#   locate          plocate
#   keybindings-menu  lua behaviour, reached through a helper that is not
#                     installed here
bar-text-color
mise-work-path
locate
keybindings-menu

# --- content assertions that do not hold on this platform ------------------
#   clipboard, notification-send, agent-usage-fireworks-scanner
# kitty-config fails because a migration calls gum, and the shim only reaches
# PATH by being installed at /usr/local/bin -- the right shape for a checkout
# and the wrong one here.
clipboard
notification-send
agent-usage-fireworks-scanner
kitty-config
system-sleep-ownership-migration

# system-sleep-ownership-migration is here because it fails on every run on a
# workstation -- this tree's umask there is 0002 -- and on the runner
# *intermittently*, which no single-run gate can distinguish from a fix. It is
# listed rather than removed because it fails more often than it passes here,
# and a build that randomly red for a flaky upstream test teaches people to
# re-run CI, which is worse than a red build that names its reason.

# --- the machine the runner is --------------------------------------------

plymouth-set

legacy-power-udev-rules-migration
